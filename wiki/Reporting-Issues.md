# Reporting Issues

Bugs and feature requests go to the [issue tracker](https://github.com/Rocket012/SyncSettings/issues).

## Before you open an issue

- Update to the **latest version** of SyncSettings for your Minecraft version and loader.
- Search for an existing issue.

## Please include

- Minecraft version
- Loader (Fabric / NeoForge / Forge) + loader version
- SyncSettings version
- Launcher
- `latest.log`
- `syncsettings_changes.log` (if relevant)
- Steps to reproduce
- Expected result vs. actual result

## Privacy

Do **not** upload tokens, account data or other personal information. Redact configs if needed.
