# Compatibility

![Compatibility](https://raw.githubusercontent.com/Rocket012/SyncSettings/main/assets/headlines/headline-compatibility.png)

| | Supported |
|---|---|
| Minecraft | 1.20 – 26.x |
| Loaders | Fabric, NeoForge, Forge |
| Side | Client only |

Use the `.jar` built for your Minecraft version and loader. Profiles are shared between all versions and loaders.
