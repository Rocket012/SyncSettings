# Backups and Undo

SyncSettings keeps backups of your settings before it changes them. Open **Backups / Undo…** on the SyncSettings screen to go back to an earlier state.

## Change log

All changes and conflicts are written to `syncsettings_changes.log`. It shows which settings were changed, from where, and which values were skipped. Please attach this file when you [[report an issue|Reporting-Issues]].
