# Installation

![Fabric](https://raw.githubusercontent.com/Rocket012/SyncSettings/main/assets/badges/badge-fabric.png) ![NeoForge](https://raw.githubusercontent.com/Rocket012/SyncSettings/main/assets/badges/badge-neoforge.png) ![Forge](https://raw.githubusercontent.com/Rocket012/SyncSettings/main/assets/badges/badge-forge.png)

1. Install the loader for your Minecraft version (**Fabric**, **NeoForge** or **Forge**).
2. Download the matching SyncSettings `.jar` from Modrinth or CurseForge.
3. Put the `.jar` into the `mods` folder of your instance.
4. Start Minecraft once.
5. Open the SyncSettings screen, create or pick a profile and adjust your settings.
6. Install SyncSettings in your other instances too. They will use the same profiles.

SyncSettings is **client-side only**. You do not need it on a server.

See [[Compatibility]] for supported versions.
